# Z-Project Workplace

ورك سبيس للفصل بين المدرس والطلاب — نفس روح تصميم Bac-Taq، لكن فكرة مختلفة تمامًا.

> **حالة المشروع:** أساس شغّال (نسخة ويب للمعاينة). التغليف كـ APK جاي في مرحلة لاحقة.

## تشغيل المعاينة

```bash
npm start          # أو: python3 -m http.server 3000 --bind 0.0.0.0
# افتح http://localhost:3000
```

## اللي موجود دلوقتي

| الشاشة | الوظائف |
|---|---|
| **الرئيسية** | إحصائيات الفصل، آخر الواجبات، إعلان سريع للوحة الفصل |
| **الطلاب** | قايمة الطلاب + بحث + إضافة/تعديل + آخر 6 أيام حضور |
| **الحضور** | تسجيل حاضر/متأخر/غايب لكل طالب، «الكل حاضر»، عدّادات فورية |
| **الواجبات** | إنشاء واجب، نسبة التسليم، شريط تقدّم لكل واجب |

## البيانات
كل حاجة بتتحفظ على الجهاز في `localStorage` تحت المفتاح `zwork.v1`:

```js
{
  teacher: { name, subject },
  klass: '3/2',
  students: [{ id, name, phone, added }],
  attendance: { 'YYYY-MM-DD': { studentId: 'p' | 'l' | 'a' } },
  homework: [{ id, title, desc, due, createdAt, done: { studentId: true } }],
  board: [{ id, text, at }]
}
```

## الهوية البصرية
نفس Bac-Taq: كحلي `#0A1F4D` → `#071A3F`، ذهبي `#FFD166`، أخضر `#2ED3A3`، خط Cairo، RTL، حواف دائرية كبيرة وشيت من تحت.
