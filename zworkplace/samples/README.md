# قاعدة بيانات الطلاب — الصيغ المقبولة

ارفع أي ملف من دول من تابعة **قاعدة البيانات** في لوحة المدرس.

## المطلوب
| عمود | إلزامي | أسماء مقبولة |
|---|---|---|
| الكود | ✅ | `code` · `student_code` · `id` · `كود` · `الكود` |
| الاسم | ✅ | `name` · `full_name` · `student_name` · `اسم` · `الاسم` |
| الرقم القومي | — | `national_id` · `ssn` · `الرقم القومي` |
| الموبايل | — | `phone` · `mobile` · `الموبايل` · `تليفون` |
| ولي الأمر | — | `guardian` · `parent` · `ولي الأمر` |
| الصف | — | `grade` · `class` · `الصف` · `الفصل` |

## الصيغ
- **CSV** — فواصل `,` أو `;` أو Tab. لو فيه صف عناوين بيتم التعرف عليه تلقائيًا
  (عربي أو إنجليزي)، ولو مفيش عناوين أول عمود = كود وتاني = اسم.
- **JSON** — مصفوفة كائنات، أو `{ "students": [...] }`.
- **Excel (.xlsx)** — بيقرا أول ورقة شغل.

## شكل الكود
أي شكل شغال طوله من 3 لـ 40 حرف:
`100000001` · `A12` · `stu_7` · `3-2-15` · `S-2026-004`

ممنوع بس: المسافات والرموز زي `@ # $ %`.

## ملاحظة
الكود **حساس لحالة الحروف** (`a12` ≠ `A12`) — الأفضل تختار صيغة واحدة
(كلها أرقام، أو كلها حروف كبيرة) وتلتزم بيها.
